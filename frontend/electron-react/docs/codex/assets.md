# 静态资源规范

## 适用范围

- `src/assets/`：参与 Vite 模块解析、构建哈希和优化的图片、字体等资源
- `public/`：构建时原样复制并通过公开路径访问的资源
- `electron/`：预留的应用图标和桌面打包资源目录

## 资源选择

- 组件或页面需要导入的资源优先放在 `src/assets/`
- 必须保持原文件名、无需模块导入的资源放在 `public/`
- 安装包图标、平台图标和桌面打包专属资源放在 `electron/`，并同步配置 `electron-builder.yaml`
- 不使用不存在的 `src/static/`，也不在资源目录放置脚本或业务配置

## 维护约束

- 新增前确认是否能复用现有素材，避免重复文件和包体膨胀
- 文件名体现内容或用途，避免无意义序号；同类资源保持一致命名方式
- JSX 或运行时字符串引用 `public/` 资源时使用 `import.meta.env.BASE_URL`，或确认生成路径能在 Electron `file://` 环境中正确解析，不硬编码根绝对路径
- 替换或删除资源前搜索全部引用，并检查开发环境与打包产物中的加载路径
- 全局样式中的资源引用同时遵守 [style.md](./style.md)
